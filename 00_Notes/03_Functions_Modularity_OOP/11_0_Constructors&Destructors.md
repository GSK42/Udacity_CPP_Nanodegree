Constructors and Destructors
Every class in C++ has a constructor and destructor, even if you don’t explicitly write them. A constructor runs automatically when an object is created, allowing you to initialize it with proper values. Destructors run when the object is destroyed or goes out of scope, giving you a chance to release resources or log cleanup. Constructors can be overloaded, meaning you can provide different ways to create an object with different parameters. Together, constructors and destructors define the lifecycle of an object — setup, usage, and cleanup. This ties into a broader C++ principle called RAII (Resource Acquisition is Initialization), where resources are tied to object lifetimes for safety and reliability.
